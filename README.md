mend applies an AI-written edit to a tree of text files: it reads a patch in unified diff, SEARCH/REPLACE, V4A or JSON form, finds each edit's lines at the first of three matching tiers, and writes every change or none. Node 22, standard library only.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
